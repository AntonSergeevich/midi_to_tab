Как ставить

Аппликатуры для выбранного строя. Тот аккорд, что звучит сейчас, подсвечен.

Аккорды песни

Вся песня по тактам. Нажмите на такт — плеер перейдёт к нему. Ленту над плеером можно тянуть мышкой.

Партии

Аккорды уже готовы для всего трека. Табы делаются отдельно — для той партии, которая нужна.

Гитара, бас, барабаны и вокал по отдельности — и аккорды переслушаются заново, уже без барабанов и голоса. Сделанные табы останутся на месте.

Текст песни

Текст распознаётся по вокальной партии — так заметно точнее, чем по всему миксу.

Готовые файлы
