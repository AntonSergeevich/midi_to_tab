# MidiToTab

Перевод **целого трека**, **стема инструмента** или **MIDI-файла** в
гитарные табы: файл Guitar Pro 5 (`.gp5`), текстовая табулатура (`.txt`)
и MIDI. С тёмным графическим приложением для Windows и прослушиванием
результата.

```
Готовый трек ──разделение──▶ гитарный стем ──┐
Стем инструмента ────────────────────────────┼─распознавание─▶ MIDI ─┐
Готовый MIDI ────────────────────────────────┴──────────────────────-┼─▶ .gp5
                                                                     └─▶ .txt
```

---

## Зачем это, если конвертеры уже есть

Типовой конвертер подбирает позицию для каждой ноты отдельно: берёт
ближайший лад и идёт дальше. Из-за этого две соседние ноты арпеджио
попадают на одну струну (физически так не сыграть — предыдущая
заглушается), а рука прыгает по всему грифу.

Здесь задача решается **целиком для всей пьесы**. Для каждого созвучия
строится набор вариантов аппликатуры, а затем алгоритм Витерби выбирает
такую цепочку вариантов, которая минимизирует суммарные затраты:
перемещения руки, растяжки пальцев и повторные удары по одной струне.
Перенос руки во время долгой ноты стоит дёшево, тот же перенос в быстром
пассаже — дорого, ровно как у живого гитариста.

Результат на арпеджио C–Am–F–G из чистого MIDI, без единой подсказки:

```
e|-------------------------------|-------------------------------|
B|------------1---------------1--|----------------------------0--|
G|--------0---------------2------|------------2-----------0------|
D|----2---------------2----------|--------3-----------0----------|
A|3---------------0--------------|----3--------------------------|
E|-------------------------------|1---------------3--------------|
      C: x32010      Am: x02210        F: 133211        G: 320003
```

Это стандартные открытые аппликатуры, выведенные алгоритмом самостоятельно.

### Что ещё сделано правильно

| | |
|---|---|
| **Время** | Считается в целых тиках (48 на четверть). Такты сходятся точно, накопления ошибки нет. Триоли поддерживаются. |
| **Размер** | Берётся из MIDI, включая смену размера посреди пьесы. Не предполагается 4/4. |
| **Темп** | Читается карта темпа файла, а не одно значение на всю вещь. |
| **Лиги** | Нота через тактовую черту делится и связывается лигой, а не обрезается. |
| **Диапазон** | Ноты вне грифа переносятся на октаву или пересчитываются в отчёте. **Ничего не теряется молча.** |
| **Густые аккорды** | Если нот больше, чем струн, сохраняются мелодия и бас, режутся средние голоса — и это сообщается. |
| **Дорожки** | Читаются все, можно выбрать любые. Не «только первая». |
| **Строи** | Стандартный, Drop D/C, Eb, D, DADGAD, Open G/D, 7 струн, бас 4/5 струн, укулеле. Плюс каподастр. |

## Установка

Нужен **Python 3.10 или новее** ([python.org](https://python.org)).
При установке на Windows обязательно отметьте **«Add Python to PATH»**.

```powershell
git clone https://github.com/AntonSergeevich/midi_to_tab
cd midi_to_tab

python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

python -m pip install -r requirements.txt
```

Этого достаточно для работы с MIDI: приложение запустится и будет полностью
функционально. Вкладка «Распознавание аудио» сообщит, что модуль не
установлен, и подскажет команды — падать ничего не будет.

### Разделение трека на дорожки (отдельным шагом)

```powershell
install_separation.bat
```

Ставит Demucs (Meta, MIT) вместе с PyTorch — около 300 МБ. Модель
`htdemucs_6s` разбирает песню на шесть дорожек, включая **отдельную
гитару**.

Это самый действенный способ поднять качество табов. Распознавать чистый
гитарный стем несравнимо точнее, чем угадывать гитару внутри микса, где
её перекрывают вокал и барабаны. Если у вас уже есть стем — шаг можно
пропустить.

Разделение тяжёлое: на процессоре минута музыки обрабатывается примерно
минуту, на видеокарте в разы быстрее (определяется автоматически).
Дорожки сохраняются, так что повторно разделять один трек не придётся.

### Распознавание аудио (отдельным шагом)

```powershell
install_audio.bat
```

или вручную:

```powershell
python -m pip install -r requirements-audio.txt
python -m pip install --no-deps basic-pitch
```

**pip покажет два красных предупреждения — это нормально:** что
`tensorflow` не установлен (он и не нужен) и что `resampy 0.4.3` новее
требуемого (`resampy` нужен `basic-pitch` только для озвучки MIDI обратно
в аудио, наш конвейер эту функцию не вызывает). Связка
librosa 1.0.0 + resampy 0.4.3 + numpy 2.5.3 на Python 3.12/3.13 проверена
полным прогоном аудио → MIDI → табы.

**Ключ `--no-deps` обязателен.** В метаданных `basic-pitch` жёстко прописан
`tensorflow<2.15.1`, сборок которого нет под Python 3.11+ на Windows, —
обычная установка падает с `No matching distribution found for tensorflow`.
При этом в коде `basic-pitch` все бэкенды обёрнуты в `try/except`, и на
ONNX-модели TensorFlow не используется вообще, поэтому его отсутствие ни
на что не влияет. Реальные зависимости перечислены в `requirements-audio.txt`
и ставятся первой командой.

## Запуск приложения

```powershell
python run_gui.pyw
```

или, если пакет установлен через `pip install -e .`:

```powershell
midi2tab-gui
```

Порядок работы в окне:

1. **Что переводим** — выбрать стем или MIDI, указать папку для результата.
2. **Дорожки** — для MIDI отметить нужные (по умолчанию выбраны все со звуком, ударные исключены).
3. **Настройки** — три вкладки:
   - *Инструмент*: строй, каподастр, верхний лад, максимальная растяжка, транспонирование;
   - *Ритм*: квантизация, триоли, let ring, темп;
   - *Распознавание аудио*: пороги чувствительности, минимальная длина ноты, ограничение диапазоном.
4. **Сделать табы** — табулатура появится прямо в окне, файлы лягут в выбранную папку.

## Командная строка

```powershell
# простой случай
python -m midi2tab песня.mid

# стем в Drop D, с выводом табов в консоль
python -m midi2tab гитара.wav --tuning "Drop D (DADGBE)" --print-tab

# конкретные дорожки, каподастр, своя папка
python -m midi2tab песня.mid -t 0,2 --capo 2 -o C:\табы
```

Полный список ключей: `python -m midi2tab --help`

```powershell
build_windows.bat
```

Готовое приложение появится в `dist\MidiToTab\MidiToTab.exe` — его можно

Сборка намеренно исключает TensorFlow: распознавание работает на

600 МБ без какой-либо пользы.

## Про качество распознавания аудио

Распознаванием занимается модель **Basic Pitch** (Spotify, лицензия
Apache-2.0, работает офлайн, ничего никуда не отправляет).

Чтобы результат был чистым:

- **Подавайте именно стем**, а не общий микс. Разделить микс на дорожки
  можно, например, через Demucs или Spleeter.
- **Не выключайте «искать только в диапазоне инструмента»**. Это
  единственная настройка, которая сильнее всего влияет на результат: без
  неё модель добавляет призрачные обертоны выше грифа. На тестовом
  сигнале ограничение диапазоном убрало 4 ложные ноты из 10, оставив
  ровно 6 настоящих.
- **Поднимите «порог атаки»**, если появляются лишние ноты; **опустите**,
  если теряются тихие.
- **Оставьте включённой «Убирать призрачные обертоны»**. Модель слышит не
  только сыгранные ноты, но и их обертоны — поверх настоящего ми
  появляется тихое ми октавой выше, квинта, дуодецима. Фильтр отличает
  призрак от настоящей ноты по совокупности признаков: почти
  одновременное начало, гармонический интервал (12, 19, 24, 28, 31
  полутонов) и меньшая громкость. Настоящую громкую октаву в аккорде он
  не трогает.
- **Ограничьте одновременные голоса**, если партия одноголосая: поставьте
  1–2, и лишние наслоения уйдут.
- Сильный дисторшн, хорус и реверберация мешают распознаванию — чем
  суше сигнал, тем точнее ноты.

## Прослушивание

Готовые табы можно послушать прямо в приложении, не открывая Guitar Pro.
Ноты уходят на системный MIDI-синтезатор (в Windows это «Microsoft GS
Wavetable Synth», он есть всегда). Тембр выбирается из списка: акустика
нейлон и сталь, джазовая и чистая электро, приглушённая, овердрайв,
дисторшн, флажолеты, бас, банджо.

Звучит именно то, что разложено по грифу, — то есть слышно, правильно ли
легли аппликатуры.

Кнопка «Сохранить .mid» выгружает партию с выбранным тембром для любого
плеера или DAW.

## Что всё равно придётся доделать руками

Инструмент даёт **очень хороший черновик**, а не готовую к печати
табулатуру. В Guitar Pro или TuxGuitar обычно стоит:

- расставить направления боя на аккордах;
- проставить приёмы: хаммер-он, пул-офф, слайды, вибрато, бенды —
  из MIDI они в общем случае не выводятся;
- проверить места, где алгоритм выбрал удобство вместо привычной
  аппликатуры;
- упростить пассажи, идиоматичные для клавиш, но неудобные на гитаре.

Открыть `.gp5` можно в [TuxGuitar](https://sourceforge.net/projects/tuxguitar/)
(бесплатно) или Guitar Pro 7/8. Оттуда же — экспорт в PDF и печать.

**Про названия с кириллицей.** Формат GP5 хранит текст не в юникоде, а в
8-битной кодировке. Кодировка подбирается автоматически по названию файла:
для кириллицы это `cp1251`, и приложение сообщает об этом в отчёте. На
русской Windows Guitar Pro покажет название правильно; если в каком-то
редакторе вместо букв появятся кракозябры — просто переименуйте вещь
внутри редактора, на сами ноты это не влияет.

## Разработка

```powershell
python -m pip install pytest
python -m pytest -q
```

52 теста: точность разложения длительностей, заполнение тактов при
размерах 4/4, 3/4, 6/8, 5/4, 7/8, 12/8, лиги через тактовую черту,
восстановление открытых аппликатур, отсутствие повторов струны в
арпеджио, обработка нот вне диапазона, кириллица в названиях, отсев
призрачных обертонов, обратный пересчёт высот при прослушивании.

### Структура

| Файл | Назначение |
|------|-----------|
| `midi2tab/timing.py` | Целочисленное музыкальное время, разложение длительностей |
| `midi2tab/tuning.py` | Строи, каподастр, гриф |
| `midi2tab/midiin.py` | Чтение MIDI: дорожки, карта темпа, карта размеров |
| `midi2tab/audioin.py` | Аудио → MIDI через Basic Pitch |
| `midi2tab/arrange.py` | Раскладка по грифу (динамическое программирование) |
| `midi2tab/gp5out.py` | Запись Guitar Pro 5 |
| `midi2tab/asciiout.py` | Текстовая табулатура |
| `midi2tab/cleanup.py` | Отсев призрачных обертонов и лишних голосов |
| `midi2tab/separate.py` | Разделение трека на дорожки через Demucs |
| `midi2tab/playback.py` | Прослушивание с выбором тембра |
| `midi2tab/theme.py` | Тёмное оформление окна |
| `midi2tab/convert.py` | Конвейер целиком |
| `midi2tab/gui.py` | Окно приложения |
| `midi2tab/cli.py` | Командная строка |
