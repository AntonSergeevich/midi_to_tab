# NASLUX — промо

Ветка `promo` — только реклама: ролики, план, музыка, исходники съёмок.
Кода сайта здесь нет, он в ветке `claude/epic-mccarthy-sl30hz`.

## Что здесь

| Папка | Что лежит |
|---|---|
| [`PLAN.md`](PLAN.md) | Анализ конкурентов, контент-план на 4 недели, правила ролика и метрики |
| [`videos/`](videos) | Готовые ролики: вертикальный 9:16 (VK Клипы, Shorts, TikTok, Reels) и горизонтальный 16:9 (YouTube, VK Видео, Rutube), а также раскадровки в PNG |
| [`music/`](music) | Гимн NASLUX — фон для роликов |
| [`raw/`](raw) | **Сюда загружайте свои съёмки**: гитару, вокал, лицо в кадре |
| [`cuts/`](cuts) | Сюда кладём нарезки из ваших съёмок со вставками экрана NASLUX |
| [`tools/make_promo.py`](tools/make_promo.py) | Сборщик роликов из настоящего сайта |

## Как посмотреть

- На телефоне или компьютере: [github.com/AntonSergeevich/midi_to_tab/tree/promo](https://github.com/AntonSergeevich/midi_to_tab/tree/promo).
- Ролик: откройте `videos/`, нажмите на mp4, затем «View raw» или «Download»: ролик скачается и откроется в телефоне.
- Раскадровка без скачивания: [`videos/vertical-frames.png`](videos/vertical-frames.png),
  [`videos/horizontal-frames.png`](videos/horizontal-frames.png).

## Как загрузить видео с гитарой

1. Откройте [`raw/`](https://github.com/AntonSergeevich/midi_to_tab/tree/promo/raw) → **Add file → Upload files**.
2. Перетащите видео. Подойдёт любое: снятое на телефон, вертикальное или горизонтальное.
3. Внизу оставьте «Commit directly to the `promo` branch» и нажмите **Commit changes**.
4. Напишите в чат, что загрузили.

Ограничение GitHub — **25 МБ на файл через сайт**. Если видео больше:

- снимайте в 1080p, а не в 4K;
- или разрежьте на куски по 20–30 секунд;
- или пришлите ссылку на Яндекс Диск или Google Drive.

**Что снять, чтобы было из чего резать.** Идеи — в [`PLAN.md`](PLAN.md), неделя 1, «Пт — живое».

- 20–40 секунд: вы играете свою песню на гитаре, просто на телефон («до»).
- Крупно руки на грифе, 5–10 секунд — для вставок.
- Лицо, когда слушаете результат в наушниках, — для реакции.
- Свет из окна спереди, телефон на штативе или стопке книг.
- Только свои песни: чужие выкладывать нельзя.

**Что я сделаю.** Нарежу ролик 15–25 секунд в два формата и положу в `cuts/`:

1. Крючок — ваша гитара на телефон.
2. Экран NASLUX: «Переделать» → стиль.
3. Результат — та же песня ню-металом.
4. Ваша реакция.
5. Логотип и «naslux.ru · попробуй бесплатно».
